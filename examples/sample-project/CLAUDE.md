# Recipe Box

A small React + Vite app for saving recipes and scaling them up or down. One developer.

## Commands

- `npm run dev` starts the app at http://localhost:5173
- `npm test` runs the unit tests (Vitest)
- `npm run lint` runs ESLint

## How we work

- For anything bigger than a bug fix, use the `new-feature` skill.
- Components live in `src/components/`, one per file, with a test next to each.
- Plans go in `docs/plans/` as Markdown.
