# New feature

1. Ask me what the feature is for and who will use it. One question at a time.
2. Write a plan to `docs/plans/<feature>.md`: the screens, the data, the edge cases, the tests.
3. Wait for my OK on the plan.
4. Build it, with a test for each new component.
5. Run `npm test` and `npm run lint`, and fix anything that fails.
