# Examples

Real output from both modes, on a real video: [How we Claude Code](https://www.youtube.com/watch?v=IlqJqcl8ONE),
a 32-minute talk from Anthropic's Claude channel. The project it was checked against is made up.

- [`sample-project/`](sample-project/): "Recipe Box", a small made-up app with a `CLAUDE.md`, two
  skills and a `.claude/settings.json`. This is the "your setup" the video was compared with.
- [`sample-project/docs/HOW-WE-CLAUDE-CODE-PLAN-2026-11.md`](sample-project/docs/HOW-WE-CLAUDE-CODE-PLAN-2026-11.md):
  **plan mode.** Three items worth doing, one setting that looked done but was silently ignored,
  and the tips that didn't fit, each with a reason.
- [`drafted-skill/design-directions/SKILL.md`](drafted-skill/design-directions/SKILL.md):
  **skill mode.** The repeatable workflow in the talk (interview, then a few HTML design directions
  to pick from), drafted as a skill.
